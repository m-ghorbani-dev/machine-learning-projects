# Salary Prediction — Stack Overflow Developer Survey 2022

## Overview

This project builds a regression workflow to estimate a developer's salary using selected information from the Stack Overflow 2022 Developer Survey. The notebook trains and evaluates several regression models, and `app.py` provides a Streamlit interface for making predictions.

## Features

The model uses three input features:

- `Country` — country selected by the user
- `EdLevel` — education level
- `YearsCodePro` — years of professional coding experience

The notebook preprocesses numerical and categorical features using a scikit-learn pipeline. Categorical features are one-hot encoded, and `YearsCodePro` is scaled. The models compared in the notebook include Linear Regression, Decision Tree, Random Forest, and XGBoost regressors.

## Dataset

The dataset is provided as a compressed archive named `survey_results_public.zip`.

**Before running the notebook, extract the ZIP file** into this project directory. After extraction, the directory should contain `survey_results_public.csv` alongside the notebook.

On Ubuntu or other Linux distributions, you can extract it from the terminal:

```bash
unzip survey_results_public.zip
```

Alternatively, use your archive manager to extract the ZIP file into this folder.

The notebook expects the extracted CSV file at the path configured in its data-loading cell. If the ZIP file contains the CSV inside another folder, move the CSV into the location expected by the notebook or update the path in the notebook.

## Requirements

Activate your Python environment and install the required packages:

```bash
pip install -r requirements.txt
```

## Run the Notebook

1. Clone or download the repository.
2. Extract `survey_results_public.zip` into this project directory.
3. Confirm that `survey_results_public.csv` is in the path expected by the notebook.
4. Open `Stackoverflow2022.ipynb` in Jupyter Notebook or JupyterLab.
5. Run the cells in order to reproduce the data preparation and model-training workflow.

## Run the Streamlit App

The app expects `xgbpipe.joblib` to be in the working directory.

```bash
streamlit run app.py
```

Choose a country, education level, and years of professional experience, then select **Calculate Salary** to display the estimated salary.

## Evaluation

The notebook calculates Root Mean Squared Error (RMSE) for the regression models. Results depend on the dataset, preprocessing, library versions, and training run. Run the notebook to obtain the results for your environment.

## Notes

- Salary estimates are model predictions, not guaranteed compensation.
- The app's input categories and column names must remain compatible with those used to train the saved pipeline.
- Check the dataset's license and redistribution terms before publishing it publicly.
- Only extract the ZIP archive when needed; if you commit the ZIP, avoid also committing the extracted CSV unless you intentionally want both copies in the repository.
- The saved model file is a binary artifact. Ensure it was generated by a trusted training run and is compatible with your installed scikit-learn and XGBoost versions.
